# 居家復能計畫與練習紀錄

給**居家復能治療師、居家服務員、家屬**用的簡易工具，由「復能計畫與執行檢核」（日照版 rehab-lite）改編，兩者是分開的網頁、資料也分開。

**到宅評估 → 開立計畫 → 傳家人版連結 → 家屬／居服員每天勾選 → 傳回紀錄 → 再評估／結案**

## 依身分不同的首頁
| 身分 | 首頁 | 用途 |
|---|---|---|
| 治療師 | 待處理（還沒傳連結、超過 7 天沒收到紀錄、計畫到期）＋近 7 天在家練習情形 | 評估、開計畫、傳連結、收紀錄、再評估 |
| 居家服務員 | 今日陪練（預設只看「居家服務員」的項目） | 服務時段陪練並勾選 |
| 家屬 | 今天的練習（用語改為「長輩」） | 每天陪練勾選；也可不經評估直接挑練習 |

## 和日照版的差異
- **評估**：最想做到的事、居家環境與照顧資源（浴室止滑、馬桶扶手、洗澡椅、門檻、樓梯扶手、夜燈、走道雜物、床高、椅子、物品高度；主要照顧者、居服時數、能陪練的時間），自動建議環境調整與輔具。體能只保留 TUG、30 秒坐站，其餘收進「更多體能測試」。家屬模式把專業量表收起來。
- **計畫**：每天都可練習；執行者為家屬、居家服務員、外籍看護、長輩自己、治療師。「團體介入」改成「生活中練習」（起床後、上廁所時、吃飯時、洗澡穿衣時、看電視時、做家務時、散步外出時、聊天時、興趣時間、睡前），各附預設做法與圖片。
- **今日練習**：可依「誰來陪練」篩選。
- **家人版連結**：計畫壓縮在網址裡（約 1–2 千字元），家屬或居服員用手機打開就能看今天的練習（附圖）並勾選，紀錄存在對方手機。按「傳回紀錄」會產生一段 LINE 文字和**匯入連結**，治療師點開就自動把紀錄與備註匯入對應的計畫。
- **列印**：新增「給家屬的居家練習單」（大字附圖、安全提醒、環境調整）與「貼冰箱的每週勾選表」；同意書、初評與計畫表、執行紀錄表、再評估報告、結案報告都改為居家用語。
- 沒有機構類型、團體統計、日照教學影片。

## 開發
- 程式在 `src/`，`python3 build.py` 產生單檔 `index.html`；圖片在 `assets/ex/`。
- 本機預覽：`python3 -m http.server 8863`。
- 資料存在瀏覽器 IndexedDB（`rehab-home`）與 localStorage（`rehabh:` 開頭），和日照版不互相影響。
